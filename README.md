# MyCinema — стартовая версия

Локальный каталог фильмов, сериалов, аниме и мультфильмов на Django + SQLite.

## Требования
- Python 3.12 или новее
- Windows PowerShell (команды ниже также легко адаптировать для macOS/Linux)

## Запуск в Windows
Открой PowerShell в папке проекта и выполни:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python manage.py makemigrations catalog
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Открой http://127.0.0.1:8000/

Админ-панель: http://127.0.0.1:8000/admin/

## Что уже есть
- Четыре категории контента
- Жанры и связи «многие ко многим»
- Год, описание, постер по URL
- IMDb, Кинопоиск и личная оценка 1–5
- Статус просмотра, дата просмотра
- Для сериалов — сезоны и серии
- Каталог с поиском, фильтрами и сортировкой
- Страница произведения и формы добавления/редактирования
- Тёмный интерфейс с акцентными цветами

## Важно
Это стартовая локальная версия. Перед публикацией в интернете нужно вынести SECRET_KEY в переменные окружения, выключить DEBUG, настроить ALLOWED_HOSTS, HTTPS, резервное копирование и подходящую production-базу данных.

Автоматический импорт через внешний API подключим следующим этапом. На первом этапе данные можно вносить вручную; поля и архитектура уже подготовлены.
